# bomb-timer-unlock

Список номеров установок, которым восстановлен премиум в игре «Таймер бомбы».

## Зачем это существует

Премиум покупается через RuStore Pay без авторизации VK ID, поэтому покупка
живёт на устройстве: сменил телефон — `getPurchases` её не вернёт. Сервера у
проекта нет, и восстановление делается вручную: игрок называет свой номер,
владелец сверяет платёж в Консоли RuStore и добавляет номер сюда.

## Как выдать доступ

1. Игрок присылает номер из раздела «Система» — вида `K7QM4-H2XB3`.
2. Найти его платёж в Консоли RuStore: поиск по `appUserId` (это тот же номер)
   либо по дате, сумме и последним 4 цифрам карты.
3. Добавить номер строкой в `ids` ниже и закоммитить.
4. Игрок нажимает «Восстановить покупку».

Дефис можно оставлять или убирать — приложение нормализует строку само.
Файл только выдаёт доступ: удаление номера отсюда **не** отбирает премиум у
того, кому он уже выдан.

## Почему репозиторий публичный

Приложение читает файл без токена. Приватный репозиторий потребовал бы токен
внутри APK, а такой токен извлекается разбором за пять минут и открывает доступ
к репозиторию. Здесь лежат только непрозрачные номера, по которым нельзя узнать
ни устройство, ни человека.
